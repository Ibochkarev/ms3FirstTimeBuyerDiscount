# Превью для ModStore и соцсетей

Материалы для публикации дополнения **ms3FirstTimeBuyerDiscount** на [modstore.pro](https://modstore.pro) и для превью в GitHub/соцсетях.

## Файлы

| Файл | Назначение |
|------|------------|
| **modstore-description.md** | Краткое описание для карточки ModStore (чек-лист возможностей) |
| **logo-500x375.png** | 500×375 px — логотип для карточки ModStore |
| **logo-variant-1.png** | Вариант: ценник + FTB, мятный фон |
| **logo-variant-2.png** | Вариант: подарок/бейдж «1st», синий градиент |
| **logo-variant-3.png** | Вариант: тёмный фон, акцент, «FTB Discount» |
| **banner-1200x630.png** | 1200×630 px — баннер пакета, Open Graph (соцсети, мессенджеры) |

## Использование

- **ModStore:** логотип — в карточку пакета; баннер или скриншоты — в описание/галерею по инструкции сайта.
- **GitHub / соцсети:** `banner-1200x630.png` для og:image; логотип — в описание репозитория.

Папка `_preview/` не входит в транспортный пакет установки — только для репозитория и загрузки на ModStore.
