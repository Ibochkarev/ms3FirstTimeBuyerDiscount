# First-Time Buyer Discount для miniShop3

Повышайте конверсию новых клиентов автоматически.

Модуль применяет скидку к первому заказу пользователя без купонов и ручных действий.

✔ Скидка на первый заказ  
✔ Процент или фиксированная сумма  
✔ Автоматическая проверка истории заказов  
✔ Простая настройка через системные параметры  

Отличное решение для привлечения новых клиентов и повышения доверия к магазину.
