# First-Time Buyer Discount для miniShop3

Повышайте конверсию новых клиентов автоматически.

Модуль применяет скидку к первому заказу пользователя без купонов и ручных действий.

- **Скидка на первый заказ** — автоматически для пользователей без оплаченных заказов
- **Процент или фиксированная сумма** — гибкая настройка типа и размера скидки
- **Автоматическая проверка истории заказов** — учёт оплаченных заказов через настройки miniShop3
- **Простая настройка через системные параметры** — включение, тип, значение, комбинирование с другими скидками

Отличное решение для привлечения новых клиентов и повышения доверия к магазину.
